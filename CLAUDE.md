# FoodOn - Food Ontology

Food ontology for naming food materials and their anatomical and taxonomic origins, from raw harvested food to processed food products. Based on OBO Foundry standards using the Ontology Development Kit (ODK).

## Project Structure

```
src/ontology/           # Main build directory
  foodon-edit.ofn       # EDITORS' MAIN FILE - only file editors modify directly
  foodon-odk.yaml       # ODK configuration
  foodon.Makefile       # Custom make overrides (DO NOT edit Makefile directly)
  Makefile              # Auto-generated by ODK - DO NOT EDIT
  run.sh                # Docker wrapper for ODK commands
  catalog-v001.xml      # OWL import resolution catalog
  imports/              # External ontology import modules
  components/           # Template-generated OWL components
  sparql/               # SPARQL validation queries and exports
  scripts/              # Python utility scripts
  reports/              # Auto-generated QC reports
src/templates/          # ROBOT TSV template files (source for bulk term definitions)
docs/                   # MkDocs documentation
.github/workflows/      # CI/CD (qc.yml runs tests on push, docs.yml deploys docs)
```

## Build System

Uses **ODK (Ontology Development Kit)** with **GNU Make** and **Docker**.

**Run commands via Docker wrapper:**
```bash
cd src/ontology
sh run.sh make <target>
```

### Key Make Targets

```bash
# Full release build
sh run.sh make prepare_release

# Fast release (skip imports/components refresh)
sh run.sh make prepare_release_fast

# Run all QC tests
sh run.sh make test

# Fast test (skip imports/components)
sh run.sh make test IMP=false MIR=false COMP=false

# Refresh all external imports
sh run.sh make refresh-imports

# Refresh a single import (e.g., ncbitaxon)
sh run.sh make refresh-ncbitaxon

# Regenerate a component from templates (e.g., food_materials.owl)
sh run.sh make recreate-food_materials.owl

# Clean temp files
sh run.sh make clean
```

**Useful environment variables:**
- `IMP=false` - Skip import regeneration
- `MIR=false` - Skip downloading external ontology mirrors
- `COMP=false` - Skip component regeneration
- `ROBOT_ENV='ROBOT_JAVA_ARGS=-Xmx6G'` - Set Java heap size (large ontologies need 4-6GB)

## External Imports

Managed via OntoFox (`*_ontofox.txt` config files):
- **ChEBI** - Chemical entities / food ingredients
- **NCBITaxon** - Organism taxonomy
- **COB** - Core Ontology for Biology
- **General** - Foundational OBO terms

## Template-Based Components

TSV files in `src/templates/` → ROBOT generates OWL in `src/ontology/components/`:
- `robot_animals.tsv` → animal species
- `robot_meat_cuts.tsv` → meat cuts
- `robot_plant_parts.tsv` → plant parts
- `robot_seafood.tsv` → seafood species
- `robot_pasta.tsv`, `robot_wine.tsv`, `robot_dietary_supplement.tsv` → food products
- `robot_process.tsv` → food processing methods

After editing a TSV template, regenerate with:
```bash
sh run.sh make recreate-food_materials.owl  # or appropriate component
```

## Editing Workflow

1. Edit `src/ontology/foodon-edit.ofn` in Protégé (the ONLY file to edit directly)
2. Test: `sh run.sh make test IMP=false`
3. Check `reports/foodon-base.owl-obo-report.tsv` - fix all ERRORs before committing
4. Commit `foodon-edit.ofn` and any changed template TSV files
5. CI runs automatically on push/PR

## CI/CD

- **qc.yml**: Runs `make test IMP=false PAT=false MIR=false` on push/PR to master
- **docs.yml**: Deploys MkDocs docs to GitHub Pages on push to master

## Release Artifacts

- `foodon-base.owl` - Without external imports
- `foodon-full.owl` - With all imports merged
- `foodon.owl` - Same as full (root-level copy for public URI resolution)

## Important Notes

- **DO NOT edit** `Makefile` directly — use `foodon.Makefile` for customizations
- The ontology URI is `http://purl.obolibrary.org/obo/foodon.owl`
- Reasoner: ELK (configured in foodon-odk.yaml)
- ID ranges assigned in `foodon-idranges.owl`
- SPARQL violation checks in `src/ontology/sparql/*-violation.sparql`
